第一章：认识小火箭 Shadowrocket

1.1 什么是小火箭？

小火箭 Shadowrocket 是一款专为 iOS 设备设计的网络代理客户端，支持 Shadowsocks、Vmess、Trojan 等多种主流代理协议。它不仅能帮助你访问被限制的网站和服务，还能有效保护你的网络隐私，防止数据被窃取或监控。

1.2 小火箭的核心优势

  • 用户友好：界面简洁直观，新手也能快速上手。
  • 多协议支持：兼容 Shadowsocks、Vmess、Trojan 等多种协议，适应不同网络环境。
  • 灵活配置：支持自定义 DNS、规则设置和代理策略，满足个性化需求。
  • 隐私保护：通过加密传输数据，防止 ISP 或第三方监控你的网络活动。

第三章：基础配置教程

3.1 添加服务器

  1. 打开 Shadowrocket，点击右上角 + 按钮。
  2. 选择代理类型（如 Shadowsocks、Vmess）。
  3. 填写服务器信息（地址、端口、密码、加密方式等）。
  4. 保存并返回主界面。

3.2 连接与断开

  • 连接：点击服务器名称，再点击底部 连接 按钮。
  • 断开：再次点击 连接 按钮即可。

3.3 检查连接状态

  • 成功连接后，状态栏会显示 VPN 图标。
  • 可在 Shadowrocket 主界面查看实时流量和连接时长。

第四章：高级功能与优化

4.1 自定义 DNS

优化 DNS 可以提升解析速度并避免污染：
1. 进入 设置 → DNS。
2. 添加公共 DNS（如 1.1.1.1、8.8.8.8）。
3. 启用 DNS over HTTPS (DoH) 增强隐私。

4.2 规则配置

通过规则可以实现智能分流（如国内直连、国外走代理）：
1. 进入 配置 → 规则。
2. 添加规则集（如 GFWList、自定义规则）。
3. 设置匹配策略（DIRECT、PROXY、REJECT）。

4.3 日志与调试

如果遇到连接问题，可查看日志排查：
1. 进入 日志 选项卡。
2. 检查错误信息（如超时、认证失败）。
3. 根据日志调整服务器或网络设置。

第五章：常见问题与解决方案

5.1 连接失败怎么办？

  • 检查服务器信息：确保地址、端口、密码正确。
  • 更换协议：尝试 Shadowsocks 或 Vmess 不同加密方式。
  • 网络环境：某些 WiFi 可能屏蔽代理，可切换 4G/5G 测试。

5.2 如何提升速度？

  • 选择低延迟的服务器。
  • 启用 UDP 转发（若支持）。
  • 关闭不必要的规则以减少性能开销。

5.3 是否支持多设备？

Shadowrocket 仅限 iOS 设备，但可通过订阅方式同步服务器配置到其他客户端（如 Clash、Surge）。

第六章：安全与隐私建议

  1. 定期更换密码：避免长期使用同一组认证信息。
  2. 启用 TLS 加密：Vmess 协议建议搭配 TLS 以增强安全性。
  3. 避免公共 WiFi：即使使用代理，公共网络仍可能存在风险。

FAQ

Hiddify Next 可以兼容旧版 Hiddify 吗？
Hiddify Next 完全向下兼容旧版配置，用户可直接导入原有 JSON 或 YAML 文件。系统会自动检测格式并进行迁移，非常适合升级旧环境到新版客户端。
SSR 的协议和混淆组合如何选择？
根据网络封锁情况选择合适协议和混淆组合，例如 tls1.2_ticket_auth 模拟 HTTPS 流量。选择最佳组合可提高抗封锁能力和稳定性，保证节点长期可用。
SSR 节点延迟高、丢包严重，常见排查步骤有哪些？
先用 ping 和 traceroute 检查到服务器的延迟与路由跳数；再通过测速工具测带宽并尝试更换不同出站端口或混淆方式；若仍然不稳，考虑更换节点或联系客服查看服务端链路质量。
如何在 Clash Premium 中使用 TUN 模式加速游戏？
Clash Premium 版本支持系统级 TUN 模式，可将所有 UDP 流量转发至代理节点。启用该模式后需管理员权限，并在配置文件中添加 dns 与 tun 模块，选择低延迟节点即可实现游戏加速。
Hiddify Next 如何为不同用户设置流量限制？
管理员可为每个用户设置独立带宽限制和流量配额。超过限制时，可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提升整体网络效率和公平性。
Shadowrocket 的分流规则如何支持视频加速？
通过分流规则，将流媒体域名匹配到高速节点，其他网站走普通节点。这样可以保证视频播放流畅，同时节约带宽资源，提高整体网络效率和体验。
QuantumultX 的 MITM 功能如何使用？
QuantumultX 的 MITM（中间人）功能可拦截 HTTPS 流量，用于修改或分析请求与响应。开启时需安装客户端生成的根证书，确保能正确解析加密数据。
Mellow 的 TUN 模式与系统代理有何区别？
TUN 模式拦截系统 IP 层流量，实现全局代理，而系统代理通常只影响支持代理的应用。TUN 更适合游戏、视频和全局科学上网场景，保证所有流量通过节点，提高稳定性和速度。
Potatso Lite 可以管理多少个节点？
Potatso Lite 可以管理数十个节点，适合轻量用户使用。虽然不支持批量自动更新，但可以手动添加和删除节点，结合策略组实现基本分流和管理功能。
Mihomo 的节点管理支持批量操作吗？
Mihomo 支持批量导入、删除和更新节点。通过策略组和分类管理，用户可以高效地管理数百个节点，同时进行测速和节点切换，提高操作效率。
